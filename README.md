# Mr. DeHart's Read Together Project

Static website for a structured literacy lesson library.

## Files

- `index.html` - page structure and content
- `styles.css` - site styles and responsive layout
- `script.js` - lesson data, filtering, and translation toggle
- `assets/logo.png` - site logo

## Publish On Netlify

1. Log in to Netlify.
2. Choose `Add new site` then `Deploy manually`.
3. Drag the whole project folder into Netlify.
4. Wait for the deploy to finish.
5. Add a custom domain later if you want.

## Publish On GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder.
3. Go to `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and the `/(root)` folder.
6. Save and wait for the site to publish.

## Local Preview

You can preview locally by opening `index.html` in a browser.
